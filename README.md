# Hollowbound website

Static site for the Hollowbound mobile game by Gamelor, served with GitHub Pages.

| Page | Purpose |
| --- | --- |
| `index.html` | Game landing page and support contact |
| `privacy.html` | Privacy Policy, Data Safety, data deletion, children. URL used in Google Play Console and App Store Connect |
| `terms.html` | Terms of Use |

The Word copy of the policies (`docx/Hollowbound_Policies.docx`) is kept locally and not published.
Keep it and `privacy.html` in sync when either changes.

Pages setting: Deploy from a branch, `main`, `/ (root)`.
